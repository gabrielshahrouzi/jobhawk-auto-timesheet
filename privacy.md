Privacy Policy for JobHawk Auto Timesheet

JobHawk Auto Timesheet does not collect, transmit, or sell any personal user data.

All timesheet information entered by the user (such as work hours and notes) is stored locally in the user's browser using Chrome storage. This data is only used to support the extension’s functionality of assisting users in completing JobHawk timesheets.

The extension does not send any data to external servers, does not track user activity outside of its intended function, and does not share data with third parties.

The extension only operates on the JobHawk website and only accesses data necessary to fill in timesheet fields.

If you have any questions about this privacy policy, please contact the developer.
